鐵道時刻 iOS／iPadOS 版隱私權政策

最後更新日期：2026 年 8 月 28 日

「鐵道時刻」iOS／iPadOS 版（以下稱「本服務」）由 DinLab 品牌提供（以下稱「我們」）。本政策說明我們在您使用應用程式、Widget、Live Activities、Siri／App Intents、捷徑、twrailway.app 網域下由我們營運的服務，以及相關後端服務時，如何蒐集、處理、利用及保護資料。個人資料蒐集者的法定名稱及聯絡方式列於本政策「聯絡我們」一節。

上線前待填：請補上可公開、持續有人處理的隱私權聯絡信箱。若 Apple App Store 的供應商名稱變更，應在本政策生效前同步更新。

一、適用範圍

本政策僅適用於本服務的 iOS／iPadOS 版本及其 Apple 平台延伸功能。

當您透過本服務前往台灣鐵路公司、Apple App Store 或其他第三方網站或服務後，該第三方將依其自己的條款及隱私權政策處理資料。

本服務不提供使用者帳號註冊或登入功能，也不要求您提供姓名、電子郵件、電話號碼或身分證件資料。

二、我們處理的資料

1. 行程與功能操作資料

  • 您選擇的運輸方式、起訖車站、查詢日期與時間、車次、篩選條件及功能操作。
  • 線上查詢所需的車站、日期、車次與篩選資料，會依功能傳送至我們的後端、交通部 TDX 或其他運輸資料服務。
  • 搜尋紀錄、常用或收藏路線、Widget 設定、介面語言、主題及其他偏好原則上保存在您的裝置或 iOS App Group 中。

2. 位置資料

在您授權「使用 App 期間」的位置權限後，本服務會取得單次前景位置，以在裝置上計算並顯示最近車站。依目前實作，我們不會將原始經緯度傳送至自家後端、不會以原始經緯度建立位置歷史，也不會持續進行背景定位。

定位功能由 Apple Core Location 提供。您可以拒絕或隨時在系統設定撤回位置權限，仍可手動選擇車站並使用其他主要功能。

3. 使用情形與分析資料

本服務使用 Google Analytics for Firebase 瞭解功能使用情形及改善服務。可能處理 Firebase 安裝識別碼、工作階段或類似識別資訊，以及裝置類型、作業系統、應用程式版本、語言、國家或約略區域、使用時間、應用程式啟動、畫面／工作階段、互動及技術事件。

我們不會將這些資料用於第三方廣告投放，且目前未整合廣告 SDK。

4. 當機與診斷資料

本服務使用 Firebase Crashlytics，可能處理當機堆疊、錯誤訊息、相關應用程式狀態、裝置型號、作業系統、應用程式版本、安裝識別碼及其他診斷資訊，以分析及修復錯誤。

我們不會刻意在當機報告中加入姓名、電子郵件、電話或原始位置。

5. 推播通知資料

本服務使用 Apple Push Notification service（APNs）與 Firebase Cloud Messaging 接收服務或版本相關通知。Apple 與 Google 可能處理 APNs 裝置 token、Firebase 安裝識別碼與推播註冊資訊，以便將訊息送達裝置。

依目前實作，應用程式會將 APNs token 交給 Firebase，但不會將 FCM 註冊 token 上傳至自家後端。我們不使用本服務帳號建立個人化通知檔案。

6. 網路與伺服器紀錄

當應用程式連線至我們的後端、TDX 或其他運輸資料服務時，相關服務的代管與網路基礎設施可能處理 IP 位址、請求時間、HTTP 方法、所請求的 API 路徑、應用程式版本、回應狀態與處理時間。API 路徑或請求內容可能反映車站、日期或車次等查詢條件。

iOS 版依功能可能透過我們的後端，或直接連線至 TDX／相關運輸資料服務。我們的後端可能使用 IP 位址執行速率限制及資安防護；雲端服務供應商的存取紀錄可能依其預設或我們的設定保留相關資訊。

7. 一次性購買與訂閱資料

既有車站 Widget 權益可透過 Apple App Store 的一次性應用程式內購買取得；本服務另會提供自動續訂訂閱，以解鎖購買畫面所列的持續性進階功能，例如 Live Activities 及 Siri 整合。付款方式、帳單與交易由 Apple 處理，我們不會取得完整信用卡或銀行帳戶資料。

為確認、續訂、撤銷與恢復權益，Apple StoreKit 可能向應用程式提供商品代碼、交易識別碼、購買及到期時間、訂閱狀態、撤銷狀態及 App 識別資訊。依目前主分支實作，權益狀態保存在裝置或 iOS App Group，未傳送至我們的後端。

若訂閱正式版本採用伺服器端交易驗證或 App Store Server Notifications，我們會在啟用前更新本政策，說明傳送欄位、使用目的與保存期間。Apple 另會依其政策處理交易資料。

8. Widget、Live Activities 與鎖定畫面資料

為提供 Widget 與 Live Activities，本服務可能將您選擇的車站、行程、車次、出發／抵達時間、延誤或行車狀態、介面語言及購買／訂閱權益保存在裝置上的 iOS App Group 或 ActivityKit 系統儲存區，並顯示在主畫面、鎖定畫面、Dynamic Island、Apple Watch、Mac、CarPlay 或其他支援的 Apple 系統介面。

這些介面可能在裝置鎖定時仍可被旁人看見。請只為您願意公開顯示的行程啟用 Live Activity，並可隨時在系統或應用程式中結束。

若 Live Activity 僅由裝置端更新，ActivityKit push token 不會上傳至我們的後端；若正式版本啟用伺服器遠端更新，我們會在啟用前更新本政策，說明 ActivityKit push token、行程識別資料及其保存與刪除方式。

9. Siri、App Intents、捷徑與系統建議

本服務可透過 App Intents 將查詢時刻、選擇車站或操作行程等功能提供給 Siri、Apple Intelligence、Spotlight、捷徑與其他 Apple 系統體驗。當您使用這些功能時，Apple 可能依其政策處理您的語音、轉錄文字、捷徑設定、互動及裝置資訊；本服務會收到完成該動作所需的結構化參數，例如起訖車站、日期、時間或車次，並可能像一般 App 內查詢一樣傳送至我們的後端或運輸資料服務。

是否顯示建議、保留捷徑或使用個人化 Siri 功能由您的 Apple 裝置與帳號設定控制。除非您另行啟用，我們不會取得 Siri 所處理的原始錄音。

三、處理目的

我們僅在提供及改善本服務所需範圍內處理資料，目的包括：

  • 提供列車時刻、即時狀態、票價、車站、Widget 與最近車站功能；
  • 提供 Live Activities、Siri／App Intents、捷徑與 Apple 系統介面整合；
  • 儲存裝置端偏好、搜尋紀錄、Widget 設定與購買／訂閱權益；
  • 傳送服務、版本更新或維運通知；
  • 分析功能使用情形、改善介面與穩定性；
  • 偵測、避免及調查濫用、詐欺、異常流量與資安事件；
  • 遵守法律義務、處理爭議並維護合法權益。

四、利用期間、地區、對象及方式

利用期間

  • 裝置端資料：保存至您在應用程式內刪除、移除相關 Widget／捷徑／Live Activity、清除或移除應用程式為止；Apple 仍可能在重新安裝後回復合法購買與訂閱狀態。
  • 後端快取：透過我們後端取得的班次、票價與路線結果可能以查詢條件短期快取，於期限屆滿、服務執行個體終止或遭汰除時刪除。
  • 監控與安全紀錄：依資安、除錯及雲端供應商設定所需期間保留，並在目的消失或法定／契約保存期間屆滿後刪除或去識別化。
  • Firebase：由 Google 依個別產品及我們的控制台設定保存。例如 Google 目前說明 Crashlytics 的當機堆疊與相關識別碼通常保存 90 天；Google 可能更新其保存政策。
  • App Store 交易資料：由 Apple 依適用法律、Apple 媒體服務條款與其保存政策處理。

利用地區

資料可能在台灣及 Apple、Google、Google Cloud、TDX 或其他服務供應商設有設施的國家或地區處理。部分供應商採全球基礎設施，資料可能跨境傳輸。我們會依適用法令及契約採取合理保護措施。

利用對象

  • 我們及經授權、確有業務需要的維運人員；
  • Apple Inc. 及其關係企業（App Store、StoreKit、APNs、Core Location、ActivityKit、Siri、Apple Intelligence、Spotlight、捷徑及相關作業系統服務）；
  • Google LLC 及其關係企業（Firebase、Google Analytics 及 Google Cloud）；
  • 交通部 TDX、台灣鐵路公司及提供相關運輸資料所必要的服務；
  • 協助代管、傳輸、監控或安全防護的服務供應商；

六、您的選擇與權利

依適用法令，您得就我們持有且可識別為與您相關的個人資料，請求查詢或閱覽、製給複製本、補充或更正、停止蒐集／處理／利用，或請求刪除。

您也可以：

  • 在 iOS／iPadOS 設定中撤回位置、通知、Siri 與搜尋相關權限或關閉建議；
  • 結束 Live Activity，或移除 Widget、捷徑與鎖定畫面設定；
  • 在 Apple 帳號的訂閱管理介面取消訂閱；
  • 在應用程式內刪除搜尋紀錄或收藏項目；
  • 移除應用程式，以刪除本機保存資料；
  • 透過下方聯絡方式提出資料權利請求。

本服務沒有帳號系統，因此沒有可刪除的本服務帳號。部分診斷資料僅以輪替識別碼或去識別形式保存，若我們無法合理驗證或定位特定資料，可能無法回應特定資料項目的存取或刪除要求；我們仍會說明處理結果。依法或為建立、行使、防禦法律權利所必須保留的資料，不在立即刪除範圍內。

七、不提供資料的影響

拒絕位置權限將無法自動尋找最近車站，但仍可手動選站；停用通知將無法接收推播；不啟用 Live Activities 或 Siri／捷徑不影響 App 內主要時刻查詢；未購買或訂閱則無法使用購買畫面列明的付費功能；拒絕必要的網路或查詢資料，可能使線上時刻、即時資訊或票價功能無法運作。

八、資料安全

我們採取與風險相稱的技術及組織措施，包括 HTTPS 傳輸、存取權限控管、敏感資訊管理、必要的請求防護，以及避免在應用程式日誌記錄憑證或完整上游回應。任何系統均無法保證絕對安全；如發生依法應通知的資料事件，我們將依適用法令處理。

九、兒童與青少年

本服務提供一般交通資訊，不以兒童為主要對象，也不明知蒐集兒童的姓名或聯絡資料。若法定代理人認為兒童在未經適當同意下提供了個人資料，請與我們聯絡。
